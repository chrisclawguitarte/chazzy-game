# Greek Mythology Guesser

A browser party game where 1–4 players guess a randomly described Greek god, Titan, or primordial deity.

## Play

Open `index.html` in a browser, or serve the folder with any static file server.

## Verify

```bash
npm run check
```

This regenerates the SVG game assets, validates the mythology data/configuration, and builds a static `dist/` copy.
